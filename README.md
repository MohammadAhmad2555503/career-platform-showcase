# Career Platform Showcase

Production-oriented personal career platform built with Next.js, TypeScript, Tailwind CSS, Supabase, Resend, global search, private CMS foundations, and contact workflows.

## Why It Matters

Career Platform is a personal career hub built like a real product: public portfolio, writing/archive areas, CV centre, project pages, contact pipeline, private admin foundation, typed content contracts, and Supabase-backed persistence.

## Employer-Relevant Highlights

- Next.js App Router with TypeScript and Tailwind CSS.
- Supabase-backed content model with RLS-aware schema design.
- Admin-only CMS foundation with no public registration route.
- Validated contact API with honeypot, rate limiting, database inbox capture, and Resend delivery.
- Typed content layer with safe local seed content and Supabase repository path.
- Search, sitemap, robots, metadata, error, loading, and not-found routes.
- Designed to avoid fake personal facts until real administrator-approved content is entered.
